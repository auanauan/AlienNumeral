# 👽 ตัวแปลงตัวเลขมนุษย์ต่างดาว (Alien Numeral Converter)

เว็บแอปพลิเคชันสำหรับแปลงตัวเลขลึกลับของมนุษย์ต่างดาวเป็นตัวเลขธรรมดาที่เข้าใจง่าย พร้อมอินเทอร์เฟซที่สนุกและน่าตื่นตาตื่นใจ!

## ✨ คุณสมบัติ

- 🚀 แปลงตัวเลขมนุษย์ต่างดาวเป็นตัวเลขปกติได้อย่างแม่นยำ
- 🧠 รองรับกฎการลบของมนุษย์ต่างดาว (เช่น AB = 4, AZ = 9)
- 📊 แสดงการแยกย่อยการคำนวณให้เห็นแต่ละขั้นตอน
- 🎵 เพลงพื้นหลังสไตล์ Pokemon พร้อม visual equalizer
- 🎨 อินเทอร์เฟซที่สวยงามพร้อมอนิเมชัน Pokemon
- 📱 รองรับการใช้งานบนมือถือ (Responsive Design)

## 🛸 สัญลักษณ์มนุษย์ต่างดาว

| สัญลักษณ์ | ค่า |
|----------|-----|
| A | 1 |
| B | 5 |
| Z | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| R | 1000 |

## 🧮 กฎการลบพิเศษ

มนุษย์ต่างดาวใช้วิธีลบเพื่อให้เขียนได้สั้นลง:

- **A** หน้า **B** หรือ **Z** → AB = 4, AZ = 9
- **Z** หน้า **L** หรือ **C** → ZL = 40, ZC = 90
- **C** หน้า **D** หรือ **R** → CD = 400, CR = 900

## 📋 ตัวอย่างการใช้งาน

```
AAA → 3
LBAAA → 58
RCRZCAB → 1994
```

## 🚀 วิธีการใช้งาน

1. เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์
2. ใส่ตัวเลขมนุษย์ต่างดาวในช่องข้อความ (เช่น RCRZCAB)
3. กดปุ่ม "🚀 แปลงเลย!" หรือกด Enter
4. ดูผลลัพธ์และการแยกย่อยการคำนวณ

## 🎮 คุณสมบัติพิเศษ

- **เสียงเอฟเฟกต์**: เสียงคลิกเมื่อกดปุ่ม
- **เพลงพื้นหลัง**: เพลงสไตล์ Pokemon 4 เพลง เล่นแบบสุ่ม
- **Visual Equalizer**: คลิกเพื่อเล่น/หยุดเพลง
- **ตัวอย่างแบบคลิก**: คลิกตัวอย่างเพื่อทดลองใช้งาน
- **Pokemon Animation**: Pikachu และ Charizard บินไปมาบนหน้าจอ

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5**: โครงสร้างหน้าเว็บ
- **CSS3**: การจัดสไตล์และอนิเมชัน
- **JavaScript (ES6+)**: โลจิกการแปลงและ UI
- **Web Audio API**: เล่นเสียงเอฟเฟกต์และเพลงพื้นหลัง

## 🎯 Algorithm

โปรแกรมใช้อัลกอริทึมการแปลงที่:
1. ตรวจสอบคู่การลบก่อน (AB, AZ, ZL, ZC, CD, CR)
2. แปลงสัญลักษณ์เดี่ยวทีละตัว
3. บวกค่าทั้งหมดเข้าด้วยกัน
